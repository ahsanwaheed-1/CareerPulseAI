# 💼 CareerPulse AI - AI Resume & Career Advisor

**CareerPulse AI** is an intelligent career growth dashboard, ATS (Applicant Tracking System) resume auditor, and cover letter optimizer built with Python, Streamlit, LangChain, and OpenAI. It empowers job seekers and professionals to analyze, optimize, and elevate their job applications for target roles.

---

## Deployed link:

https://career-pulse-ai.streamlit.app/

## 🌟 Key Features

* **🎯 ATS Compatibility & Resume Scoring**: Calculates overall ATS scores, pinpoints missing keywords, and evaluates structural impact.
* **⚡ High-Impact Bullet Point Rewriter**: Transforms weak bullet points into compelling action-verb + metric-driven achievement statements.
* **🎯 Job Description Alignment**: Matches resume experience against specific target job posts to identify critical qualification gaps.
* **📧 Cover Letter Optimization**: Reviews cover letter drafts for tone, engagement, and alignment with corporate cultures.
* **🎨 Modern Slate Dashboard UI**: Designed with a sleek dark slate glassmorphism visual theme, model selection, temperature tuning, and instant preset quick actions.

---

## 🛠️ Tech Stack

* **Frontend & Framework**: Streamlit
* **LLM Orchestration**: LangChain (`langchain-openai`, `langchain-core`)
* **AI Model**: OpenAI GPT-4o / GPT-4o-mini
* **Styling**: Modern CSS3 (Dark Slate Theme with Glassmorphism & Custom Accents)

## 🚀 Quick Start & Local Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Usman-Sultan7/review-pulse-ai.git
   cd review-pulse-ai
   ```

2. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**:
   ```bash
   streamlit run app.py
   ```

4. **Access the App**:
   Open `http://localhost:8501` in your browser, enter your OpenAI API key in the access portal, and start optimizing your career application!
